# Polski dla Orca / Polish Language Pack for Orca

Nieoficjalny, społecznościowy pakiet języka polskiego (`pl`) dla [Orca IDE](https://onorca.dev), przygotowany w **Eszetael_Lab**.

- **Wersja bazowa Orca:** `1.4.263`
- **Pokrycie tłumaczenia:** `100%` (wszystkie 19 217 przetłumaczalnych kluczy UI)
- **Typ wtyczki:** `data` (tylko tłumaczenia — nie uruchamia żadnego kodu i nie wymaga dodatkowych uprawnień)

---

## Instalacja / Installation

### Z Marketplace w Orca
1. Otwórz **Settings → Plugins** w Orca.
2. Wyszukaj **Polski** (`eszetael.polski`) i kliknij **Install**.
3. Przejdź do **Settings → General → Language** i wybierz **Polski**.

### Z linii poleceń (CLI)
```bash
orca plugin install Eszetael/orca-polski
```
*(Na Linuxie, jeśli komenda `orca` koliduje z czytnikiem ekranu GNOME, użyj `orca-ide plugin install Eszetael/orca-polski`.)*
